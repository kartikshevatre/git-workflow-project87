
# Git Workflow Project

## Project Overview
A Python application packaged using Docker for repeatable deployment.

## Requirements
- Python 3
- Docker Desktop

## Run Locally
```bash
python app.py
```

## Docker Build
```bash
docker build -t git-workflow-demo .
```

## Docker Run
```bash
docker run --rm git-workflow-demo
```

## Expected Output
Welcome to the Git Workflow Demo!
Project: Git Workflow and Project Baseline
Status: Ready to build and collaborate.
